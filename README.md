# .github

Org-level defaults for Emun Labs: the [contributing guide](CONTRIBUTING.md), pull request and issue templates, and an opt-in DCO workflow. The public org landing page lives in [`profile/README.md`](profile/README.md).

The profile graphics are generated, not drawn by hand. Their source is `emun-labs/brand/github-profile/` in the Emun Labs site repository.
