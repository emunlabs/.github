# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately to **security@emunlabs.com**. Please do not open public GitHub issues or pull requests for security problems.

To encrypt your report, use our OpenPGP key:

- User ID: Emun Labs, Inc. <security@emunlabs.com>
- Fingerprint: `B47E 9F58 829D A2E5 3E7F  8B74 3816 94AE 61AD 7421`
- Public key: [security-emunlabs-pubkey.asc](https://github.com/emunlabs/.github/blob/main/security-emunlabs-pubkey.asc)
- Key type: Ed25519 (sign/certify) with a Curve25519 encryption subkey; expires 2028-10-27

Please verify the fingerprint above before relying on the key. The key is not uploaded to any keyserver.

## Scope

Applies to code and services in repositories under the github.com/emunlabs organization and Emun Labs, Inc.-operated services.

## Response time

We'll acknowledge your report within 3 business days.

Please include a description, affected component/version, steps to reproduce, and impact. We ask that you give us reasonable time to fix an issue before public disclosure.
